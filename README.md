# Desafio Toro

Projeto desenvolvido por Valéria Harumi Nishimura para processo avaliativo da vaga de pessoa desenvolvedora front-end na toro investimentos.

## Comandos executáveis

Para iniciar o projeto rodar o comando:

### `npm install`

Para instalar as dependêcias necessárias do projeto.

### `npm start`

Esse comando inicia o projeto localmente e pode ser acessado pela seguinte url.\
[http://localhost:3000](http://localhost:3000)

### `npm test`

Para rodar os testes do projeto.
